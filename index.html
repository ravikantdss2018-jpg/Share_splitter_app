Install ExpenseSplitter

Android

Open the published link in Chrome, tap the three-dot menu, then choose Install app or Add to Home screen.

iPhone or iPad

Open the link in Safari, tap Share, choose Add to Home Screen, then tap Add.

Windows

Open the link in Edge or Chrome and select the install icon in the address bar, or use the browser menu and choose Install.

Mac

In Safari choose File → Add to Dock. In Chrome, use the install icon in the address bar.
